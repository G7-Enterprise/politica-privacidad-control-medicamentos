<h1>Política de Privacidad — Control de Medicamentos</h1>
<p><strong>Última actualización: 26 de julio de 2026</strong></p>

<h2>1. Responsable</h2>
<p>Esta aplicación es desarrollada, administrada y mantenida de forma independiente. Es un proyecto de software creado por su autor; no existe ninguna corporación, institución de salud, farmacéutica ni organización gubernamental detrás de ella.</p>

<h2>2. Qué datos almacena la aplicación</h2>
<p>La aplicación almacena la información única y exclusivamente de forma local en el almacenamiento interno del dispositivo del usuario. Los datos que la aplicación gestiona para su funcionamiento son:</p>
<ul>
    <li><strong>Perfiles de Pacientes:</strong> Nombres o alias utilizados para separar los registros y cronogramas de diferentes miembros de la familia o pacientes dentro del mismo dispositivo.</li>
    <li><strong>Gestión de Medicamentos:</strong> Nombres de los fármacos, dosis asignadas, frecuencias de consumo, horarios de toma, alarmas de aviso y control de existencias en el inventario digital.</li>
    <li><strong>Historial Médico Real y Cronogramas:</strong> Registro de tomas completadas, fechas de cumplimiento, dosis omitidas y recordatorios de próximos consumos.</li>
    <li><strong>Documentación de soporte:</strong> Archivos adjuntos (imágenes de recetas, cajas de medicamentos o documentos PDF almacenados localmente) que el usuario decida vincular a sus registros.</li>
</ul>

<h2>3. Dónde se almacenan los datos (Cifrado Local)</h2>
<p>Todos los datos se guardan estrictamente de forma local en el dispositivo del usuario, utilizando una base de datos interna cifrada para garantizar la protección familiar. La aplicación no envía, no recopila, ni transmite ningún tipo de dato médico o personal a servidores externos, bases de datos en la nube ni a terceras personas.</p>
<p>Las copias de seguridad que el usuario decida generar de manera manual se guardan exclusivamente en el destino que el propio usuario elija de forma independiente. El resguardo, la seguridad y el contenido de esas copias archivadas son responsabilidad exclusiva del usuario.</p>

<h2>4. Notificaciones y alarmas del sistema</h2>
<p>La aplicación utiliza los servicios de notificación locales del propio sistema operativo del dispositivo para activar los recordatorios de horarios de medicación y alertas de bajo inventario. No se hace uso de servicios de mensajería o notificaciones push en la nube para el envío de estas alertas críticas.</p>

<h2>5. Gestión de suscripciones y pagos</h2>
<p>El procesamiento y la gestión de las licencias anuales de la aplicación se realizan a través de la plataforma de pagos segura Paddle. El desarrollador de la aplicación no recibe, no procesa y no almacena datos de tarjetas de crédito, cuentas bancarias ni información de transacciones financieras. Las políticas y condiciones de privacidad de Paddle aplican para todas las operaciones de pago.</p>

<h2>6. Permisos solicitados al dispositivo</h2>
<ul>
    <li><strong>POST_NOTIFICATIONS:</strong> Necesario para mostrar las alertas locales y recordatorios de toma de medicamentos.</li>
    <li><strong>SCHEDULE_EXACT_ALARM:</strong> Fundamental para configurar el temporizador del sistema y emitir avisos con precisión horaria absoluta, garantizando que no se pierda ninguna dosis.</li>
    <li><strong>USE_FULL_SCREEN_INTENT:</strong> Permite el despliegue de alertas de medicación a pantalla completa incluso con el dispositivo bloqueado.</li>
    <li><strong>READ_MEDIA_IMAGES:</strong> Permite al usuario adjuntar fotografías de recetas médicas o cajas de medicamentos a sus registros locales.</li>
    <li><strong>RECEIVE_BOOT_COMPLETED:</strong> Reprograma de manera automática los recordatorios y alarmas locales tras reiniciar el teléfono.</li>
</ul>

<h2>7. Protección de menores de edad</h2>
<p>Esta aplicación no recopila ni solicita información personal de forma automatizada. Cualquier registro relacionado con un menor de edad debe ser ingresado y gestionado directamente por un adulto responsable (padre o tutor) a través de los perfiles de la aplicación.</p>

<h2>8. Derechos del usuario sobre el control de su información</h2>
<p>El usuario cuenta con el dominio absoluto y total de cada uno de los datos ingresados en el sistema:</p>
<ul>
    <li>Puede extraer y exportar de forma íntegra toda su información mediante la herramienta nativa de copia de seguridad local.</li>
    <li>Puede eliminar permanentemente toda la información registrada desinstalando la aplicación o limpiando los datos de la app desde los ajustes del sistema operativo.</li>
</ul>
<p>Dado que no existen servidores centralizados, no hay almacenamiento externo al que se pueda solicitar acceso, rectificación o eliminación.</p>

<h2>9. Cláusula de exención de responsabilidad profesional</h2>
<p>Esta aplicación es estrictamente una herramienta organizativa de control de inventario y recordatorios. <strong>No es un dispositivo médico</strong>, no está diseñada para el diagnóstico de dolencias, no prescribe tratamientos de salud ni ofrece asesoramiento clínico. La responsabilidad de seguir las indicaciones médicas recae completamente en el usuario. El desarrollador de la aplicación no tiene afiliación alguna con entidades de salud.</p>
